# ConsoleEmulator
A user-friendly, easily configurable program that emulates a terminal. 

## How to run ConsoleEmulator:

### Windows:
Two compiled versions are provided:
- Windows on `x86-64` , with OpenJDK 17 included (referred to as `windows-amd64`)
- Windows on `x86-64` , without OpenJDK 17. (referred to as `windows-amd64-nojava`)

The former is a larger download, but is more likely to run. The latter is a smaller download, but you will need to install [OpenJDK 17](https://adoptium.net/).

### Linux:
Three compiled versions are provided:
- Linux on `x86-64` (referred to as `linux-amd64`)
- Linux on 32bit `arm` (referred to as `linux-aarch64`)
- Linux on 64bit `arm` (referred to as `linux-arm`)

### macOS:
A compiled version is not available for Macs, as I need a Mac to compile for a Mac. Instead, get the source code, and run it using the [Processing IDE](https://processing.org/download)
